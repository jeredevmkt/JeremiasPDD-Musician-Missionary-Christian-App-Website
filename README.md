# 🎵 JeremiasPDD - Missionary & Christian Music Platform

Official Missionary & Christian Music website for **JeremiasPDD**. This is a dedicated Christian missionary platform designed to spread the **Gospel of Jesus Christ** globally through music, faith-driven performances, and kingdom resources.

---

## 🌟 Project Purpose

This platform serves as a digital ministry tool to share the message of Christ, connect with global mission fields, provide high-quality gospel music resources, and invite believers to partner with the mission.

---

## 🛠️ Technologies

- **Frontend:** Next.js 15 + React 19 + TypeScript
- **Styling:** Tailwind CSS
- **Database:** Neon (Pure PostgreSQL)
- **Hosting:** Vercel

---

## 🚀 Features

- **🌍 4-Language Localization (i18n):** The entire website is now fully translated into **4 languages**, breaking cultural barriers to reach diverse mission fields worldwide.
- **🙏 Powerful Testimonies:** A dedicated space sharing real stories of faith, transformation, and God's work through the ministry.
- **💝 Kingdom Donation Gateway:** Integrated a secure and seamless giving system for supporters to partner financially with missionary projects and music productions.
- **📖 Refreshed About Section:** An upgraded, deeply personal page highlighting JeremiasPDD’s testimony, mission vision, and calling.
- **🎵 Media & Feeds:** Showcase of songs, albums, embedded YouTube videos, and a live Instagram feed integration.
- **📧 Subscriptions & Inquiries:** Fully functional contact form paired with an engaging pop-up newsletter system.
- **📱 Ultra-Responsive:** Modern, fluid interface optimized for all device sizes (Mobile + Desktop).
- **🌙 Dark Mode:** Sleek visual design tailored for low-light environments.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com
cd jeremiaspdd-missionary-and-musician-website
```

### 2. Install Dependencies

```bash
yarn install
```

### 3. Setup Neon Account

1. Go to [neon.com](https://neon.com)
2. Create a new project.
3. Copy your project database **URL** from the Settings section.

### 4. Setup Environment Variables

Create a `.env.local` file in the root directory:

```env
DATABASE_URL=your_supabase_url_here
NEXT_PUBLIC_CONTACT_EMAIL=example@email.com
```

### 5. Start Development Server

```bash
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
